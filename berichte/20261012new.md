### <?php ?>

```sh 
<?php

```
Bedeutung: PHP-Block öffnen / schließen

### echo 
Beispiel: 
```sh 
<?php
echo 'Hello World!<br>';

?> 
```
``` echo "Hallo", $name; ```
Bedeutung: echo wird verwendet, um einen Text auszugeben. Mehrere Werte sind mit Komma möglich  

### Arrays
Beispiel: 
```sh
$cars = array("Volvo", "BMW", "Toyota");
echo count($cars);
```
Bedeutung: Ein Array ist eine Variable, die mehrere Werte unter einem Namen halten kann. Man kann die Werte mittels eines Indexes auslesen.

### Functions 
Beispiel: 
```sh
function myMessage() {
  echo "Hello world!";
}

myMessage();
```
Bedeutung: Funktion ist ein benannter Codeblock, den man einaml schreibt und beliebig oft aufrufen kann.

### if / elseif /else 
Beispiel: 
```sh
$t = 14;
if ($t < 20) {
  echo "Have a good day!";
}
```  
Bedeutung: Bedingungen.     
Wenn die Angegebene Bedingung erfüllt ist, dann wid der Inhalt in der Bedingung ausgefüllt.     
If ist die Bedingung, und else die Gegen Bedingung        

### switch / case / default
```sh
switch (expression) {
  case label1:
    //code block
    break;
  case label2:
    //code block;
    break;
  case label3:
    //code block
    break;
  default:
    //code block
}
```
Bedeutung: Mehrfachauswahl
Dabei wird gesucht, welche Bedingung der Code erfüllt, und jeweils dann die Bedingund ausgeführt.

### Notenverwaltung: 
```sh
<form method="post">
    Noten (mit Komma getrennt): <input type="text" name="noten">
<button>Berechnen</button>
</form>
<?php
if (isset($_POST['noten'])) {
    $noten = explode(",", $_POST['noten']);
 
    $positiv = 0;
    foreach ($noten as $note) {
        if ($note <= 4) {
            $positiv++;
        }
    }
 
    $durchschnitt = array_sum($noten) / count($noten);
    $beste = min($noten);
    $schlechteste = max($noten);
?>
<table border="1">
<tr><td>Noten</td><td><?php echo implode(", ", $noten); ?></td></tr>
<tr><td>Durchschnitt</td><td><?php echo round($durchschnitt, 2); ?></td></tr>
<tr><td>Beste Note</td><td><?php echo $beste; ?></td></tr>
<tr><td>Schlechteste Note</td><td><?php echo $schlechteste; ?></td></tr>
<tr><td>Positive Noten</td><td><?php echo $positiv; ?></td></tr>
</table>
<?php } ?>
```
### Erklärung: 
Getestet wurde mit den Noten 1, 3, 5, 2: Durchschnitt 2,75, beste Note 1, schlechteste Note 5, positive Noten: 3.        
Formular: Der Benutzer tippt in ein Textfeld mehrere Noten ein, durch Kommas getrennt, zum Beispiel 1,3,5,2.       
If-Abfrage: Mit isset($_POST['noten']) wird geprüft, ob das Formular abgeschickt wurde.        
explode(): Die Funktion trennt den Eingabetext an jedem Komma und legt die einzelnen Noten in einem Array $noten ab.       
foreach-Schleife: Sie nimmt nacheinander jede Note aus dem Array. Eine If-Abfrage prüft, ob die Note 4 oder besser ist (<= 4). Trifft das zu, wird der Zähler $positiv um 1 erhöht.         
Berechnungen:       
array_sum() addiert alle Noten und die Division durch count() ergibt den Durchschnitt 2,75.        
min() liefert die beste Note, denn in der Schule ist die kleinste Zahl die beste. 1 ist sehr gut         
max() liefert die schlechteste Note = 5         
Tabellenausgabe: Eine HTML-Tabelle zeigt die eingegebenen Noten (mit implode() wieder zu einem Text zusammengefügt) und alle Ergebnisse an.  
round() rundet den Durchschnitt auf 2 Nachkommastellen.       

Anmerkung: die Formatierung der Tabelle wurde mittels Claude überarbeitet und verschönert, damit man es gut erkennen kan

### Passwort- Gernerator
```sh
<form method="post">
    Länge: <input type="number" name="laenge" value="12"><br>
<input type="checkbox" name="gross"> Großbuchstaben<br>
<input type="checkbox" name="klein"> Kleinbuchstaben<br>
<input type="checkbox" name="zahlen"> Zahlen<br>
<input type="checkbox" name="sonder"> Sonderzeichen<br>
<button>Erzeugen</button>
</form>
<?php
if (isset($_POST['laenge'])) {
    $zeichen = "";
 
    if (isset($_POST['gross'])) {
        $zeichen .= "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    }
    if (isset($_POST['klein'])) {
        $zeichen .= "abcdefghijklmnopqrstuvwxyz";
    }
    if (isset($_POST['zahlen'])) {
        $zeichen .= "0123456789";
    }
    if (isset($_POST['sonder'])) {
        $zeichen .= "!@#$%&*?";
    }
 
    if ($zeichen == "") {
        echo "Bitte mindestens eine Option wählen.";
    } else {
        $passwort = "";
        for ($i = 0; $i < $_POST['laenge']; $i++) {
            $passwort .= $zeichen[rand(0, strlen($zeichen) - 1)];
        }
        echo "Passwort: " . htmlspecialchars($passwort);
    }
}
?>
```
### Erklärung:
Beispiel: Länge 8, möglich sind Großbuchstaben und Zahlen.  
Mögliches Ergebnis: K7QX2M9B. Das Passwort ist zufällig, bei jedem Klick auf "Erzeugen" sieht es anders aus.            
Formular: Der Benutzer legt in einem Zahlenfeld fest, wie lang das Passwort sein soll, und wählt aus, welche Zeichenarten vorkommen dürfen:   Großbuchstaben, Kleinbuchstaben, Zahlen und Sonderzeichen.     
Äußere If-Abfrage: Mit isset($_POST['laenge']) wird kontrolliert, ob das Formular schon abgeschickt wu rde. Beim ersten Öffnen der Seite wird der PHP-Teil übersprungen.       
Vier If-Abfragen:  isset() prüft ob der Inhalt der Abfrage erfüllt wird.       
Ist das der Fall, hängt .= die dazugehörigen Zeichen an den String $zeichen an. So entsteht ein Vorrat aus allen erlaubten Zeichen.      
If / else: Ist $zeichen am Ende noch leer,  erscheint ein Hinweis (Bitte ,mindestens eine Option wöhlen). Sonst folgt die Passwort-Erzeugung.
for-Schleife: Sie läuft genau so oft, wie die gewünschte Länge angibt. In jedem Durchlauf zieht rand() eine zufällige Zahl zwischen 0 und der letzten Position der Zeichen im  Array.         
Das Zeichen an dieser Position wird an $passwort angehängt. Die letzte Position ist strlen($zeichen) - 1, weil die Zählung bei 0 beginnt.       
Ausgabe: echo zeigt das fertige Passwort an. htmlspecialchars() wandelt Zeichen wie & in HTML-sichere Schreibweise um, damit der Browser sie korrekt darstellt.
