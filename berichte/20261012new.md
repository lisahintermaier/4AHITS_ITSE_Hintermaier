# Wiederholung PHP

## Übung 2.1 (PHP)

### <?php ?>
Beispiel: ``` <?php echo 1; ?> ```
Bedeutung: PHP-Block öffnen / schließen

### echo 
Beispiel: ``` isset($x) ```
Bedeutung: prüft, ob Variable gesetzt ist und nicht null ist

### isset() 
Beispiel: ``` echo "Hallo", $name; ```
Bedeutung: Text ausgeben - mehrere Werte sind mit Komma möglich

### global 
Beispiel: ``` global $x; ```
Bedeutung: globale Variable in Funktion nutzen 

### if / elseif /else 
Beispiel: 
```sh
if (5 > 3) {
  echo "Have a good day!";
}  
```  
Bedeutung: Bedingungen
Anmerkung: Codezeilen aus w3schools - https://www.w3schools.com/php/php_if_else.asp

### switch / case / default
```sh
switch (expression) {
  case label1:
    //code block
    break;
  case label2:
    //code block;
    break;
  case label3:
    //code block
    break;
  default:
    //code block
}
```
Bedeutung: Mehrfachauswahl
Anmerkung: Codezeilen aus w3schools - https://www.w3schools.com/php/php_switch.asp

